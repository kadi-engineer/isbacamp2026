# AGENTS.md – Fragrance of Zion Travel Companion

## Project Overview

A mobile-first event companion app for the Fragrance of Zion church travel trip. Passcode-protected, it gives trip members a centralized hub for logistics and community sharing.

## Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | TanStack Start |
| Frontend | React 19, TanStack Router v1 |
| Build | Vite 7 |
| Styling | Tailwind CSS 4 |
| Database | Netlify Database (managed Postgres) via Drizzle ORM beta |
| Language | TypeScript 5 |
| Deployment | Netlify |

## Directory Structure

```
src/
  routes/
    __root.tsx          # HTML shell, global head tags
    index.tsx           # Entire client app: passcode gate + all tab components
    api/
      announcements.ts  # REST API – GET / POST / DELETE announcements
db/
  schema.ts             # Drizzle ORM table definitions
  index.ts              # Netlify Database Drizzle client
netlify/
  database/
    migrations/         # Auto-applied SQL migrations (generated by drizzle-kit)
drizzle.config.ts       # Points drizzle-kit at netlify/database/migrations/
public/                 # Static assets
```

## Key Decisions

- **Single-file app** (`src/routes/index.tsx`) – All tab components live in one file since the app is small and self-contained.
- **Passcode stored in sessionStorage** – Unlocked state survives page refreshes within the browser tab but clears on close.
- **Announcements via Netlify Database** – The only dynamic data. Admin auth uses the same shared passcode (1925).
- **Static data** – Schedule, rooms, and departure lists are hardcoded arrays in `index.tsx`. Edit them directly when trip details change.
- **No external auth library** – The passcode check is intentionally simple (shared secret).

## Coding Conventions

- Tailwind CSS for all styling; no CSS modules.
- TanStack Start API routes (`server.handlers`) for server-side endpoints.
- Drizzle ORM beta (`drizzle-orm@beta`) required for Netlify Database adapter.
- Run `npx drizzle-kit generate` after schema changes; migrations go to `netlify/database/migrations/`.
- Import paths must include `.js` extension for TS → ESM (e.g., `from './schema.js'`).

## Content Editing Guide

| What to change | Where |
|---|---|
| Schedule days/events | `SCHEDULE_DAYS` array in `src/routes/index.tsx` |
| Room assignments | `ROOMS` array in `src/routes/index.tsx` |
| Departure bus/passengers | `BUSES` array in `src/routes/index.tsx` |
| Help contact numbers | `HelpBanner` component in `src/routes/index.tsx` |
| App passcode | `PASSCODE` in `src/routes/index.tsx` AND `ADMIN_PASSCODE` in `src/routes/api/announcements.ts` |
